# Diseño instruccional

1. Define audiencia, nivel de partida y 3–6 objetivos observables (explicar, aplicar, contrastar, construir, evaluar).
2. Para sesiones de taller, propuesta inicial: 15–25% presentación y contexto, 55–70% práctica guiada y autónoma, 10–20% revisión y cierre. Adapta según complejidad.
3. Cada bloque: pregunta motivadora → explicación corta → ejemplo trabajado → ejercicio → feedback → síntesis.
4. Alterna slides narrativas con preguntas de recuperación cada 5–10 minutos. Ajusta duración realista de actividades.
5. Las slides de ejercicio deben poder ser usadas desde dispositivos personales sin perder progreso. Incluye también una solución explicada para el docente.
6. Si fusionas presentaciones, crea un mapa de cobertura por objetivo: cubierto, parcial, ausente, duplicado, contradictorio.
7. Documenta decisiones: qué se conserva, qué se sintetiza, qué se sustituye por interacción y qué se elimina por duplicado.
8. Exige referencias verificables para afirmaciones técnicas, históricas o estadísticas; no conviertas ejemplos inventados en hechos.
